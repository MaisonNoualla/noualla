TYPEFACE
  Wordmark files use a safe serif fallback (Georgia/Times/Noto Serif) so
  they display consistently in any program, even without internet access.
  On the live website itself, the wordmark is set in Fraunces (already the
  site's display typeface) for a slightly warmer, more editorial feel.
